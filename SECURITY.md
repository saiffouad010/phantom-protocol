# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Use a private GitHub Security Advisory for the repository, or contact the repository owner through the private contact channel configured on GitHub.

Do not include passwords, access tokens, private keys, or other sensitive values in a report. Provide the affected file or URL, a minimal reproduction, the potential impact, and any safe mitigation you identified.

## Scope

This policy covers the PHANTOM PROTOCOL source code, the Cloudflare Pages Function under `functions/`, and the public website deployment. Third-party services, external social accounts, and the underlying Cloudflare platform are outside the project's direct control and should be reported to their respective owners.

Security reports will be reviewed before any public disclosure. Please allow reasonable time for validation and remediation.
